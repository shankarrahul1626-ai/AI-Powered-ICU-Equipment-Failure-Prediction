# ICU Equipment Failure Prediction & Predictive Maintenance

## Project Overview

This project predicts ICU medical equipment failures using Machine Learning and Predictive Analytics.

The system analyzes sensor and operational data from medical devices such as:

- Ventilators
- Patient Monitors
- Infusion Pumps
- Oxygen Concentrators

The project includes:

- Failure Prediction
- Remaining Useful Life Prediction
- Anomaly Detection
- Power BI Dashboard
- FastAPI Deployment

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-Learn
- XGBoost
- FastAPI
- Power BI

## Models

### Random Forest

Predicts equipment failures.

### XGBoost

Advanced failure prediction model.

### Isolation Forest

Detects anomalous equipment behavior.

### Random Forest Regressor

Predicts Remaining Useful Life (RUL).

## Dashboard

Power BI dashboard provides:

- Equipment Health Monitoring
- Failure Trends
- Risk Analysis
- Anomaly Detection
- RUL Monitoring
